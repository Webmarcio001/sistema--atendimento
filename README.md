# Sistema de Atendimento

Sistema robusto de gerenciamento de tickets de atendimento ao cliente com suporte a fila, priorização, chat em tempo real e autenticação JWT.

## 🚀 Tecnologias

- **FastAPI** - Framework web assíncrono de alta performance
- **PostgreSQL** - Banco de dados relacional robusto
- **SQLAlchemy** - ORM para Python
- **Pydantic** - Validação de dados
- **JWT** - Autenticação segura
- **WebSockets** - Chat em tempo real
- **Docker & Docker Compose** - Containerização
- **Alembic** - Migrations do banco de dados

## 📋 Funcionalidades

- ✅ Gerenciamento de tickets/chamados
- ✅ Sistema de fila de atendimento
- ✅ Priorização de tickets
- ✅ Chat em tempo real entre cliente e atendente
- ✅ Sistema de usuários (clientes, atendentes, admin)
- ✅ Autenticação e autorização com JWT
- ✅ Categorias de atendimento
- ✅ Histórico de atendimentos
- ✅ Relatórios e estatísticas
